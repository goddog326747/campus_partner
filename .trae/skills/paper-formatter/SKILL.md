# 论文格式规范技能 (Paper Formatter)

## 职责

作为格式规范Agent，负责：
1. 应用格式模板
2. 统一引用格式
3. 生成目录和图表
4. 最终排版检查
5. 输出可提交版本

## 格式规范

### 1. 页面设置

```yaml
纸张: A4
页边距:
  上: 2.54cm
  下: 2.54cm
  左: 3.17cm
  右: 3.17cm
行距: 1.5倍
段落: 首行缩进2字符
```

### 2. 字体字号

| 元素 | 字体 | 字号 | 样式 |
|------|------|------|------|
| 正文 | 宋体/Times New Roman | 小四(12pt) | 常规 |
| 一级标题 | 黑体 | 三号(16pt) | 加粗 |
| 二级标题 | 黑体 | 四号(14pt) | 加粗 |
| 三级标题 | 黑体 | 小四(12pt) | 加粗 |
| 图表标题 | 宋体 | 五号(10.5pt) | 常规 |
| 参考文献 | 宋体 | 五号(10.5pt) | 常规 |

### 3. 标题编号

```
第1章 引言
  1.1 研究背景
    1.1.1 行业现状
    1.1.2 技术挑战
  1.2 研究意义
第2章 相关工作
...
```

### 4. 图表格式

**图格式**：
```
图1-1 系统架构图
[图片]
图1-1 系统架构图
```

**表格式**：
```
表1-1 实验参数设置
[表格]
表1-1 实验参数设置
```

**公式格式**：
```
E = mc² (1-1)
```

### 5. 引用格式

**GB/T 7714-2015 标准**：

期刊：
```
[1] 作者. 文章标题[J]. 期刊名, 年份, 卷(期): 页码.
[1] 张三, 李四. 深度学习研究进展[J]. 计算机学报, 2023, 46(5): 1001-1015.
```

会议：
```
[2] 作者. 文章标题[C]//会议名称. 地点: 出版社, 年份: 页码.
[2] Wang W, Liu Y. Deep Learning Methods[C]//Proc. of CVPR. Los Angeles: IEEE, 2023: 123-130.
```

专著：
```
[3] 作者. 书名[M]. 地点: 出版社, 年份.
[3] 周志华. 机器学习[M]. 北京: 清华大学出版社, 2016.
```

## 使用流程

1. 接收定稿内容
2. 选择格式模板
3. 应用格式规范
4. 生成目录图表
5. 格式检查
6. 输出最终版本

## 注意事项

- 严格按照学校/期刊要求
- 保持格式一致性
- 注意中英文混排
- 检查打印效果
